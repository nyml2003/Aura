# 产品需求

本文档从**产品/用户视角**描述博客系统的功能与体验目标，不规定具体 URL、路由或实现技术。

---

## 一、产品定位与范围

- 站点是**混合内容**：除了博文，还有**前端小游戏、互动 demo** 等。首页与整体流程要从「可读 + 可玩」出发。
- **Item 抽象**：不少博客/CMS 会把「文章」「项目」「链接」等统一成「条目」概念，再按类型或标签筛选；首页展示「推荐条目」，列表页按类型/时间/标签分页查。

---

## 二、体验与视觉

- **主次分明**：页面内要有清晰的视觉层次——导航/站点标识为一级，推荐卡片为内容主体，页脚/次要链接弱化。
- **可读与对比**：正文与背景对比足够，字号与行距保证可读；链接、按钮等可点击元素在静态与 hover 态下可区分。

---

## 三、功能范围与优先级（概要）

| 功能/页面 | 优先级 | 说明 |
|-----------|--------|------|
| 首页（推荐 + 瀑布流） | 第一期 | 首页展示**推荐**内容：由管理员手动打标（如精选、推荐到首页）的 **item** 以**瀑布流**呈现；每一项 item 可能是文章、小游戏/demo 等；滑到底可加载更多。链接与返回由系统生成（完整 URL）。同时支持按类型/标签/时间等的**分页查询**列表。 |
| 列表页（分页查询） | 第一期 | 分页展示 item；每页 N 条，明确「第几页、共几页」；点击某项进详情。链接由系统下发（完整 URL）。 |
| 文章详情 | 第一期 | 展示单篇文章正文与元信息；支持返回首页或列表（链接由系统给出，完整 URL）。 |
| 小游戏 / demo 详情 | 第一期 | 展示可玩的小游戏或互动 demo；即玩即走；支持返回首页或列表。 |
| 搜索 | 第一期 | 输入关键词，按类型/标签等筛选（可选）；结果以列表或卡片形式展示，分页；点进某项进详情。链接由系统下发（完整 URL）。 |
| 文章管理列表 | 第一期 | 看到所有文章（含草稿、已发布、私密），按状态筛选、翻页；列表中的链接由系统生成（完整 URL）。 |
| 内容管理列表 | 第一期 | 展示全部 item（文章 + 小游戏等），按类型/状态筛选、分页；支持「推荐到首页」打标、取消推荐、排序或批量操作；点击某项进编辑或详情。链接与操作入口由系统下发（完整 URL）。 |

---

## 四、非功能需求

| 类别 | 目标 | 说明 |
|------|------|------|
| **流畅（首屏与关键路径）** | 从输入 URL 到页面不抖动为止约 100ms | 关键路径（首页、列表、文章详情等）：从用户输入 URL 到页面渲染完成且不再发生布局抖动的时延，目标约 100ms 内。首屏一次到位，不做骨架屏。达标方式由技术侧选型（如首屏数据与 HTML 一起下发）。 |
| **链接与地址** | 链接由系统统一生成（完整 URL） | 列表、详情、分页、返回等所有链接和地址由系统生成并下发为**完整 URL**，页面只展示和跳转，不自己拼地址。 |

## 五、页面拆解（职责与体验指标）

| 页面 | 入口说明（产品） | 职责（做什么） | 体验指标 |
|------|------------------|----------------|----------|
| **首页** | 站点首页 | 展示「推荐到首页」的 item 瀑布流；首屏内站点名/一句话 + 导航 + 首批推荐卡片；滑到底加载更多推荐；每张卡片可点击进入对应详情。 | 从输入 URL 到页面不抖动为止约 100ms；下滑加载更多顺畅；卡片点击有反馈。 |
| **列表页（分页查询）** | 从导航等进入；可按类型、标签、时间等条件进入对应列表 | 分页展示 item；每页 N 条，明确「第几页、共几页」；点击某项进详情。 | 从输入 URL 到页面不抖动为止约 100ms；翻页反馈明确；链接由系统下发（完整 URL）。 |
| **文章详情** | 从首页卡片、列表项或搜索结果点击进入 | 展示单篇文章正文与元信息；支持返回首页或列表（链接由系统给出，完整 URL）。 | 从输入 URL 到页面不抖动为止约 100ms；排版可读；返回入口明确。 |
| **小游戏 / demo 详情** | 从首页卡片、列表项或搜索结果点击进入 | 展示可玩的小游戏或互动 demo；支持返回首页或列表。 | 从输入 URL 到页面不抖动约 100ms（可玩区域可懒加载）；返回入口明确。 |
| **搜索** | 从导航或站点内搜索入口进入 | 输入关键词，按类型/标签等筛选（可选）；结果以列表或卡片形式展示，分页；点进某项进详情。 | 输入与筛选有即时反馈；结果列表从输入 URL 到页面不抖动约 100ms；链接由系统下发（完整 URL）。 |
| **内容管理列表** | 登录后默认进入或从后台导航进入 | 展示全部 item，按类型/状态筛选、分页；支持「推荐到首页」打标、取消推荐、排序或批量操作；点击某项进编辑或详情。 | 列表加载与翻页顺畅；打标有即时反馈；链接与操作入口由系统下发（完整 URL）。 |

---

## 六、分工说明

- **产品**只界定**页面有哪些、从哪进、能去哪**（用产品语言描述）。
- **具体 URL、路由规则、链接格式（后端下发的为完整 URL）**由**研发/技术设计**负责，产品不规定路径写法。
- **页面跳链、URL、路由规则**：**具体路径格式、参数、链接生成规则（下发的链接为完整 URL）**由**研发/技术设计**在接口与前端设计中确定。
